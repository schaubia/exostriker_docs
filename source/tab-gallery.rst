Every tab in context
====================

These are actual full-window Qt captures of version 0.97.1. Each accessible tab in the maintained main-window Designer form is opened separately, including nested parameter, prior, kernel, plot-option and dataset tabs. Use the chapter links below to avoid scrolling through unrelated workflows. The compact :doc:`screenshots` walkthrough remains the starting point.

These are **empty GUI placeholders**. No observations, invented data, fitted models, posterior samples or orbital histories are loaded. The author will supply real screenshots/examples to replace them. Default fields and disabled controls are shown as they appear in an empty session. No private session or physical monitor capture is used.

The six numbered regions are menus, scientific plots, session/calculation controls, parameters/options, accessory tools, and dataset controls. Each image includes a brief explanation of the selected tab and important actions. Click an image for full resolution.

The current capture contains **249 full-window views**.
