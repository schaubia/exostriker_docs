Credits and citation
====================

.. _credits:

Cite Exo-Striker using **ASCL ascl:1906.004** and the citation metadata in the
application checkout's ``CITATION.cff``. Record the version/source revision used.
The project is maintained by Trifon Trifonov, with contributors listed in the
application credits and repository history.

The original manual credits Xianyu Tan and Man Hoi Lee for dynamical RV fitting,
Man Hoi Lee for Keplerian and N-body routines, Jakub Morawski for RVmod development,
Grigorii Smirnov-Pinchukov for installer work, and Stefan Dreizler for the AMD
stability diagnostic. Preserve these contributions when reusing the project.

Acknowledge scientific dependencies actually used in your analysis, including
GLS/MLP, TLS, wotan, celerite, batman, TTVFast, emcee, dynesty, SWIFT and REBOUND as
applicable. Native RV/photometry/timing models are also provided by the current
Fortran backend; batman and TTVFast no longer describe every calculation.
Consult each dependency's citation metadata and the GUI **Help → Credits**.
Interactive plotting uses a bundled pyqtgraph implementation, and the GUI uses Qt.
